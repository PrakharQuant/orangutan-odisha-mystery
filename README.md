# 🦧 The Odisha Orangutan Mystery

Five baby orangutans reportedly appeared in Odisha, India.

How could orangutans native to Southeast Asia end up thousands
of kilometres away?

This interactive visualization explores possible explanations.

## ⚠️ Important

The routes shown are illustrative hypotheses and should not be
interpreted as confirmed animal movements.
